# Basic HTML Website – Sanju Rathee

**Project URL:** [https://github.com/22948sr/Single-Page-CV/tree/main](https://github.com/22948sr/Single-Page-CV/tree/main)

**Roadmap.sh Project:** [https://roadmap.sh/projects/basic-html-website](https://roadmap.sh/projects/basic-html-website)

A multi-page HTML-only website built as part of the roadmap.sh frontend developer learning path. The goal of this project is to structure a website using semantic HTML — covering headers, footers, navigation, main content, and sidebars — without any CSS styling. Styling will be addressed in a separate project.

---

## Project Goal

Learn how to:
- Create multiple pages on a website and link them together
- Structure a website semantically using HTML
- Lay out content in a way that is ready for CSS styling later
- Add SEO meta tags to every page

---

## Pages

| Page | File | Description |
|------|------|-------------|
| Homepage | `index.html` | Hero section, 3-column layout (Projects, Work Experience, Education), Teacher Reviews, Footer |
| Projects | `projects.html` | Table listing all personal and client web projects with descriptions and links |
| Articles | `articles.html` | List of articles on web development, SEO, WordPress, and AI tools |
| Contact | `contact.html` | Contact details and a form with name, email, phone, subject, service, budget, and message fields |

---

## File Structure

```
/
├── index.html        ← Homepage
├── projects.html     ← Projects page
├── articles.html     ← Articles page
├── contact.html      ← Contact page with form
└── README.md         ← Project documentation
```

---

## Features

- Shared navigation bar on all pages linking to Home, Projects, Articles, and Contact
- Table-based layout to replicate the mockup structure (header, hero, 3-column section, reviews, footer)
- SEO meta tags on every page (description, keywords, author, robots)
- Open Graph (OG) tags on every page for social media sharing
- Favicon linked in the head of every page
- Contact page includes a full form with fields: Full Name, Email, Phone, Subject, Service Required, Budget, and Message
- Semantically correct HTML using tags like header, nav, main, section, article, address, fieldset, and footer
- No CSS — pure HTML structure ready for styling in a future project

---

## How to Use

1. Download or clone this repository
2. Open `index.html` in any modern web browser
3. Use the navigation bar to switch between pages
4. No dependencies, build tools, or a server are required
